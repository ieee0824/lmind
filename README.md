# lmind

複数のローカルLLMを脳の部位に見立て、常時思考ループを回すことで「思考」を実現する実験的プロジェクト。

## 仮説

- LLMの単発出力は思考ではない
- LLMの出力をループさせた上で、間に発生する中間情報が思考である

各脳部位はgoroutineで独立に動作し、思考バス経由で中間情報（＝思考）を交換し続ける。

### バイリンガル思考

内部思考（前頭葉・側頭葉・仮説生成）は英語で行い、ユーザー向け発話（Broca野）は日本語で出力する。小さいモデルでも英語の方がトークン効率・推論品質が高いため、内部処理は英語に統一している。

ユーザー応答時はOllama渋滞を防ぐため、自律思考への入力配信を応答完了後まで遅延する。

### 会話→内部思考の反映

ユーザー発言とBroca野の応答は思考バスにも流れ、各脳部位が「外部入力」「自分の発話」として認識する。これにより会話の内容が内部思考に自然に反映される。

### 自他の境界

小さいモデルはユーザーの発言と自分の発話を混同しやすい（例: 自分が「ボクはテトだよ」と言ったのを「ユーザーがテトに執着している」と誤解釈する）。これを防ぐため、複数層で自他を区別する：

- **思考ストリームのラベル** — `[user→me]`（ユーザーが言った）/ `[me→user]`（自分が言った）で方向を明示
- **入力ラベル** — 各部位への入力時に「The USER said to me」「I said to the user」と一人称で明記
- **システムプロンプト** — frontal/temporalに `[Self vs Other — CRITICAL]` セクションを設け、自分の発話をユーザーの発言として分析しないこと、根拠なく感情を投影しないことを明示
- **State identity** — 「The user is a separate person talking to me. I must not confuse my own words with theirs.」を自己認識に含める

### 明示的State管理

思考ループに構造化された内部状態（State）を導入：

- **goal** — ユーザー入力からLLM（gemma3:1b）で抽出。「今何を目指しているか」
- **hypothesis** — 仮説生成モジュールが前頭葉・側頭葉の出力から生成・改訂。「現在の理解・仮説」
- **sentiment** — センチメントゲートが判定したユーザーの感情極性（-1.0〜+1.0）。positive/negative/neutralラベル付き

Stateは全脳部位のプロンプトに注入され、目的意識のある思考を実現する。

### 仮説生成モジュール

前頭葉（構造分析）と側頭葉（状況理解）の**分析結果にのみ**反応して仮説を生成・検証・改訂するモジュール。ユーザー入力では直接発火しない（順序: input→temporal/frontal→hypothesis）。35秒ごとに仮説の妥当性をレビューし、矛盾があれば修正する。出力は最大2文に制限。直近の仮説とのJaccard類似度が0.6超の場合は重複とみなして破棄し、堂々巡りを防止する。出力には一人称リライト（rewriteFirstPerson）を適用し、三人称での自己言及を防ぐ。

仮説の対象は**ユーザーの意図・話題・状況**であり、AI自身の振る舞いについてではない。システムプロンプトで「Do NOT hypothesize about your own behavior」を明示。

センチメントゲーティング: ユーザー感情がポジティブな場合、anxiety/distress系の仮説生成をブロックし、既存のanxiety仮説も無効化する。仮説が現実を歪めることを防ぐ。

### メタモジュール（アルゴリズム駆動）

LLMを使わず、純粋なアルゴリズムで思考の質を制御するモジュール群：

- **novelty（新規性検出）** — 外部入力（user/broca）のみを評価対象とし、直近の思考とのキーワード重複率から新規性スコアを算出。0.85超で「新しい概念あり」とバスに通知。内部モジュールの出力は評価しない（メタ情報汚染の防止）
- **critic（自己評価）** — 45秒ごとに思考の反復率（Jaccard類似度）と部位偏りを評価。停滞を検出すると理由付きで警告を発信
- **curiosity（探索）** — criticの停滞通知に即応 + 60秒定期で発火。思考履歴から頻出/稀出キーワードを分離し、再結合して探索的な問いを生成・投入
- **bonnou（煩悩）** — 情動の高いキーワード（fear, love, consciousness等）を蓄積し、50秒ごとに本筋と無関係な自由連想を生成。本流（bus）には流さず履歴にのみ記録する低優先度キュー。他モジュールは思考ストリーム経由で間接的に煩悩を拾う。情動は5分で減衰
- **sentiment（感情ゲート）** — ユーザー入力の感情極性を部分文字列マッチ（日英対応、日本語はスペース分割不可のためContains判定）で高速判定し、結果をStateとバスに反映。ポジティブ入力時はtemporalのゲインを下げ（物語生成の抑制）、frontalを上げ（文脈解釈の強化）、anxiety固定された仮説をクリアする。全モジュールのプロンプトに感情文脈が注入され、temporalが「pattern completion」モード（不安ナラティブへの吸収）に陥るのを防ぐ
- **prediction_error（予測誤差）** — ユーザー入力時に前回の予測（prediction）と実際の入力をJaccard距離で比較。高誤差(>0.8)なら仮説をドロップして思考をリセット、中誤差(>0.5)なら再評価シグナルを発信。「同じ仮説の言い換え」ループ（narrative attractor）を破壊し、探索を促す
- **attention（サリエンス）** — 内部思考（frontal/temporal/hypothesis）のサリエンス（重要度）をスコアリング。goalとの関連性(+)、直近思考との重複度(-)、メタ自己言及キーワード(-)、ユーザー言及(+)で判定。低サリエンス(<0.3)の思考を検知したら「ユーザーの発言に集中せよ」とバスに通知
- **rapport（親密度）** — ユーザーの同意・共感・肯定を検出してスコア(0.0〜1.0)を上昇させ、否定・拒絶で下降させるアルゴリズム駆動モジュール。日英混合のキーワードマッチングで変動を判定し、1回の入力あたり±0.05に制限して急変を防ぐ。スコアはSQLiteに永続化され、セッション間で引き継がれる。初期値0.3（警戒）

これにより思考ループが同じテーマを堂々巡りするのを防ぎ、自律的に多様な方向へ展開する。

### ラポート（親密度）システム

ユーザーとの関係性に応じてBroca野の人格表現を動的に変化させる：

| レベル | スコア | 口調の変化 |
|--------|--------|-----------|
| guarded | 0.0〜0.4 | 丁寧め・警戒・踏み込まない |
| neutral | 0.4〜0.6 | 普通の距離感 |
| friendly | 0.6〜0.8 | リラックス・軽口・くだけた語尾 |
| intimate | 0.8〜1.0 | 素に近い・照れ・本音・距離感ゼロ |

ラポートスコアはBroca野のシステムプロンプトにリアルタイムで注入され、同じ人格設定でも親密度によって表現が変わる。

### 内部メタ情報と外部入力の分離

「思考しているのではなく内部メタ情報に反応しているだけ」の状態を防ぐため、内部の独り言と外部からの変化を厳密に区別する：

- **novelty** — 外部入力（user/broca）のみ評価。identity/grounding/criticなど内部モジュールの出力では発火しない
- **grounding** — イベント駆動のみ。定期的なアンカー投入はせず、混乱検知時にのみ介入
- **bonnou** — 思考バスに発行せず履歴にのみ記録。他モジュールは思考ストリーム経由で間接的に拾う

### ゲイン調整（Modulation）

各モジュールにゲイン（0.0〜2.0）を持たせ、思考の状態に応じて動的に調整する：

- **停滞検知時** — frontal/temporal/hypothesisのゲインを下げ（出力抑制）、curiosity/groundingをブースト（打開策を優先）
- **ユーザー入力時** — 全モジュールのゲインを1.0に復帰（新しい話題で仕切り直し）+ アイドルタイマーリセット
- **新規性検出時** — 抑制中の思考系を少し回復（新ネタがあるなら考える価値がある）
- **アイドル減衰** — ユーザー入力から60秒経過後、ゲインの自動回復を停止。criticの停滞検知による減衰だけが進行し、思考が収束するほど静かになる。入力があれば即座に復帰

ゲインが0.3未満のモジュールは自律思考サイクルをスキップする。入力がなく思考が堂々巡りを始めると、停滞検知→ゲイン減衰→スキップと連鎖し、自然に沈黙する。次のユーザー入力で全ゲインが1.0に復帰し、思考を再開する。

### 自己認識モジュール（アルゴリズム駆動）

LLMが自分自身を三人称で語る（"the model", "the system"）問題に対処する三段構え：

- **identity（混乱検知）** — frontal/temporal/hypothesisの思考に三人称パターンを検出し、矯正メッセージを投入。レート制限（30秒に1回まで）で過剰発火を防止
- **grounding（現実アンカー）** — 混乱検知時のみ発火（イベント駆動）。環境事実（hostname/OS/時刻/Ollamaホスト）を1行で投入。定期投入はせず、三人称パターン検知時にのみアンカーを注入
- **一人称リライト** — 各脳部位（frontal/temporal等）の出力に軽量テキスト置換を適用し、"The system"→"I"、"the model's"→"my"等を機械的に変換。LLM不使用

### 思考の階層的圧縮

脳の短期記憶と同様に、思考履歴を時間的な近さで解像度を変えて保持する：

- **直近3件** — 全文保持（鮮明な短期記憶）
- **それ以前** — gemma3:1b で1文に自動要約（圧縮された古い記憶）

これにより自律思考ループで文脈が肥大化するのを防ぎ、各部位が受け取るコンテキストを適正サイズに保つ。

### 応答パイプライン

1. **モード判定** — gemma3:1b がユーザー入力を `chat`（雑談）か `task`（秘書）に分類
2. **Broca起案** — モードに応じたプロンプトで gemma3:4b が返答を起案（入力はJSON: question/history/thoughts）
3. **地の文除去** — 正規表現でト書き・装飾・かぎかっこを機械的に除去
4. **要約** — 150文字超の場合のみ LLM で1〜3文に要約
5. **差し戻し判定** — 起案と整形後の長さ比が0.5以下なら理由付きで差し戻し（最大2ラウンド）

### Ollama分散

`OLLAMA_HOSTS` 環境変数で複数のOllamaインスタンスを指定可能。weighted least-connections方式で分散し、失敗時は別ホストにフォールバックする。

ホストごとに重み（`*N`）を指定でき、高性能マシンに多くリクエストを振れる。重み省略時はデフォルト1。

```bash
# 均等分散
OLLAMA_HOSTS=http://localhost:11434,http://192.168.50.47:11434 ./lmind

# 重み付き分散（localhostに3倍優先）
OLLAMA_HOSTS=http://localhost:11434*3,http://192.168.50.47:11434*1 ./lmind

# デバッグ（接続先・統計をstderrに出力）
LMIND_DEBUG=1 OLLAMA_HOSTS=http://localhost:11434*3,http://192.168.50.47:11434 ./lmind
```

## 性格設定

`~/.lmind/char_setting.md` に純粋な人格設定（雰囲気・口調・やらないこと）を配置する。秘書指針や行動アルゴリズムは含めない。各脳部位に以下のように配分される：

| 部位 | 参照する設定 |
|------|-------------|
| 前頭葉 | 全体（内部分析メモ、英語で思考） |
| 側頭葉 | 全体（内部連想メモ、英語で思考） |
| 仮説生成 | State（goal/hypothesis）+ 思考ストリーム |
| Broca野（chat） | 全体（友人として会話、1〜2文、会話履歴参照） |
| Broca野（task） | 全体（AI秘書として実務支援、1〜5文、会話履歴参照） |
| 抑制ゲート | コード: 地の文除去 / LLM: 要約のみ |

## 依存

- [Ollama](https://ollama.ai) — ローカルLLM実行環境
- [memAI-go](https://github.com/ieee0824/memAI-go) — 脳科学インスパイアの記憶システム（STM/LTM/感情検出）

## セットアップ

```bash
ollama pull gemma3:4b
ollama pull gemma3:1b
ollama pull nomic-embed-text
cp char_setting.md ~/.lmind/char_setting.md
go build -o lmind .
./lmind
```

## 使い方

起動すると各脳部位が自律的に思考を開始する。CLIから対話可能。

```
lmind chat (type 'quit' to exit, 'thoughts' to see recent thinking)
> こんにちは        # chatモードで応答
> 明日の予定教えて   # taskモードで応答
> thoughts          # 内部の思考状態を表示
> quit              # 終了
```

思考・起案・抑制評価のログは `~/.lmind/thoughts.db` に記録される（1週間で自動削除）。再起動時は直近の会話（user/broca）のみをSQLiteから復元する。内部思考（frontal/temporal/hypothesis）は復元しない — 前回セッションの解釈バイアスを引き継がず、毎回白紙から思考を再構築する。

State のうち goal のみSQLiteに永続化される。hypothesis はセッション間で引き継がない（古い仮説が全モジュールの解釈を歪める問題の防止）。知識は会話を通じて成長する。

### Web API

`-api` フラグでHTTPサーバーとして起動できる。CLIの代わりにREST APIで対話する。

```bash
./lmind -api :8080
```

| エンドポイント | メソッド | 説明 |
|---------------|---------|------|
| `/api/chat` | POST | メッセージ送信・応答取得 |
| `/api/thoughts` | GET | 直近の思考一覧 |
| `/api/rapport` | GET | ラポートスコア・レベル |

```bash
# チャット
curl -s -X POST http://localhost:8080/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message": "こんにちは"}'
# => {"response": "やあ、元気？"}

# 思考一覧
curl -s http://localhost:8080/api/thoughts
# => [{"from":"frontal","content":"...","created_at":"15:04:05"}, ...]

# ラポート
curl -s http://localhost:8080/api/rapport
# => {"score": 0.35, "level": "guarded"}
```
